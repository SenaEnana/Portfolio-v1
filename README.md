# 🚀 Modern Full-Stack Portfolio

Welcome to the repository for my personal portfolio website. This project serves as a digital home to showcase my software engineering projects, technical skillset, and professional experience.

Built with a modern, high-performance web stack, it is fully responsive, optimized for SEO, and deployed globally.

---

## 🛠️ Tech Stack & Architecture

*   **Framework:** [Next.js](https://nextjs.org/) (App Router, React server components)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Utility-first CSS framework)
*   **Email Integration:** [Resend](https://resend.com/) (For reliable, transactional contact form delivery)
*   **Deployment:** [Vercel](https://vercel.com/) (Edge network hosting and continuous integration)

---

## ✨ Features

*   **Fast Loading & SEO Optimized:** Leverages Next.js Server Components, localized font loading, and strict image optimization.
*   **Dynamic Contact Form:** Integrated with Resend API for instant email notifications when users reach out.
*   **Responsive Layout:** Tailored design fluidly scaling across mobile, tablet, and desktop viewports.
*   **Project Showcase:** Interactive CRUD features/filtering to display professional work and open-source applications.

---
